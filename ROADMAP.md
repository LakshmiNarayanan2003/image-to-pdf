# Roadmap

Milestones express scope, not delivery promises. Unchecked items are not current product features.

## v0.1.0 — Core local conversion

- [x] Multiple images into one PDF, ordering, rotation, page layout and quality.
- [x] Practical local formats, honest limitations, safety caps and cleanup.
- [x] Output, privacy, accessibility and cross-browser automation.

## v0.2 — Advanced page control

- [ ] Custom dimensions and per-page margins.
- [ ] Interactive cropping and bulk rotation.
- [ ] Better page-layout preview before export.
- [ ] Export separate PDFs in a local ZIP if demand justifies it.

## v0.3 — Image fidelity and resources

- [ ] Broader TIFF corpus, including tiled/CMYK/JPEG/Fax variants and nested directories.
- [ ] HDR, wide-gamut and color-profile evaluation with visible fidelity controls.
- [ ] JPEG XL after decoder size, maintenance, licensing and browser coverage justify it.
- [ ] Additional HEIF codec and phone-photo regression fixtures.
- [ ] Streaming/worker PDF assembly and reduced peak memory for large collections.

## v0.4 — Related PDF tools

- [ ] Explore merging, mixing image/PDF pages, and output splitting without weakening local processing.
- [ ] Evaluate optional offline installability only with a cache design that cannot retain user images.

## Release quality follow-up

- [ ] Physical iOS/Android download-dialog and assistive-technology review.
- [ ] Broader native Safari/Edge and printer/color validation.
- [ ] Continuously verify the published Pages build and dependency updates.

RAW camera processing, a backend, accounts, analytics, ads and monetization are outside v0.1.0.
