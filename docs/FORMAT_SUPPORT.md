# Format support

The browser reads signatures rather than trusting extensions. Renamed PNG-as-JPEG is tested. Plausible image MIME types, octet-stream and appropriate text/XML inputs are accepted for sniffing; non-image declared types such as PDF are rejected. RAW camera extensions are rejected even when their bytes resemble TIFF. Corrupt/empty/unsupported files produce individual errors and do not block valid neighboring files.

| Format              | Decoder and verified fixture                          | Behavior / limits                                                                                                                                                                                                                      |
| ------------------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JPEG/JPG/JFIF       | Browser; baseline RGB and EXIF 1–8                    | Browser-normalized orientation, including mirrored pixels. Direct JPEG embedding only for eligible three-channel orientation-1 images without ICC. Metadata stripped. Other variants depend on the browser.                            |
| PNG                 | Browser; opaque and RGBA                              | Alpha over chosen white/black background. No 16-bit preservation guarantee.                                                                                                                                                            |
| WebP                | Browser; lossless RGB                                 | Animation uses browser default still frame; animated WebP fixture not part of release evidence.                                                                                                                                        |
| GIF                 | gifuct-js worker; real two-frame animation            | First frame only; subsequent magenta frame is explicitly excluded by PDF pixel tests.                                                                                                                                                  |
| BMP                 | Browser; uncompressed RGB                             | Unusual bit depths/compressions depend on native support.                                                                                                                                                                              |
| SVG                 | Inert DOM validation then native image rasterization  | Shapes, text, gradients and clipping subset. Script, CSS/style, events, use/image, foreignObject, entities/DOCTYPE and external references rejected. System fonts may differ. Raster PDF output.                                       |
| AVIF                | Browser; real lossless AVIF                           | Passed in the pinned Chromium, Firefox and WebKit engines; availability remains browser/codec dependent. No HDR/animation preservation claim.                                                                                          |
| HEIC/HEIF           | libheif-js WASM worker; genuine HEVC fixture          | Primary decoded image, 8-bit RGBA. No depth maps, bursts, HDR/auxiliary images or metadata preservation. Unsupported codec variants fail locally.                                                                                      |
| TIFF/TIF            | `tiff` worker; RGB single/multi-page, LZW and deflate | Supported IFDs become pages in order. Grayscale/RGB layouts supported by the decoder; limits/preflight reject unsupported bit depth/color layouts, SubIFDs, EXIF/GPS/DNG and excessive directories. JPEG/Fax/BigTIFF are not promised. |
| ICO                 | Browser; PNG-backed 32 px ICO                         | Native decoder chooses one bitmap. No user-selectable size or all-entries expansion.                                                                                                                                                   |
| RAW / DNG / JPEG XL | Rejected                                              | Export JPEG or PNG using a suitable photo tool first.                                                                                                                                                                                  |

All listed tested fixtures were converted to actual downloaded PDFs and independently rasterized in each of the three Playwright engines. This demonstrates these fixtures and code paths, not universal support for every file carrying the same extension.

## Fidelity and page policy

One accepted image becomes one page, except TIFF expansion. User ordering and rotation apply after decode. Standard and High encode JPEG at 85%/95%, limiting the longest edge to 2400/4096 pixels. Maximum keeps the decoded resolution and PNG encoding or eligible JPEG scan data. SVG is rasterized. Color-profile conversion and 8-bit decoding can alter source appearance; keep originals for archival use.

See the [README limits](../README.md#resource-limits), [test coverage](TESTING.md) and [verification record](VERIFICATION.md). Samples and fixture artwork are generated by this repository, including the HEIC fixture; no third-party photo licensing is required.
